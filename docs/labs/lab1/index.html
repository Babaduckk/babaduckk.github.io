Описание задания

Создание и развертывание статического сайта на базе MkDocs с публикацией на GitHub Pages

Цели работы

  • Освоить процесс создания статического сайта с использованием генератора документации MkDocs
  • Научиться организовывать структуру документации проекта (портфолио лабораторных работ)
  • Изучить базовые принципы работы с системой контроля версий Git и платформой GitHub
  • Развернуть статический сайт с использованием механизма GitHub Pages на домене вида username.github.io
  • Освоить базовую настройку темы оформления и конфигурационного файла mkdocs.yml

Ход выполнения

Структура проекта

├── docs
└── source
    ├── docs
    │   ├── labs
    │   │   ├── img
    │   ├── templates
    │   │   └── lab-report.html
    │   ├── about.md
    │   └── index.md
    └── mkdocs.yml
  • Из верхнеуровневой директории docs выполняется публикация статического сайта с помощью GitHub Pages
  • Поддиректория labs директории source/docs хранит поддиректорию img - изображения для отчетов и .md файлы формата lab{k}.md - отчет соответствующей работы
  • Файл lab-report.html выступает базовым шаблоном всех отчетов
  • Файлы index.md и about.md - страницы "главная" и "об авторе" соответственно
  • Конфигурация сайта задается в mkdocs.yml

Файл mkdocs.yml

site_name: Портфолио курса "Программирование на Python" и не только

nav:
  - Home: index.md
  - About: about.md
  - Labs:
      - Lab №1: labs/lab1.md
      - Lab №2: labs/lab2.md
      - Lab №3: labs/lab3.md

theme:
  name: readthedocs
  custom_dir: docs/templates
  locale: ru

plugins:
  - search
  - markdown-filter

Выбор темы

Основным критерием выбора темы была возможность (приемлемой) поддержки базового шаблона для .md файлов-отчетов. Как оказалось, не все темы удовлетворяют этому требованию: так, тема snadcn определяет сборку сайта таким образом, что шаблон не отображается на странице, тема windmill парсит файлы таким образом, что на странице появляются два набора кнопок-навигаций вперд и назад. Так как темы хотелось использовать, не разбираясь во внутренней реализации каждой, я выбрал ту, что поддерживает базовый шаболон и чей стиль (размер шрифта, цветовая гамма, расположение кнопок и меню) меня удовлетворяет
